Equinox merge codes — reference

Every merge code Equinox offers in Smart Templates, grouped as Equinox groups them, and whether the Equinox add-on fills it in letters (Word) and cover emails (Gmail). Write a code in a template between hashes, e.g. #MATTER#. Codes are filled from the matter and the recipient chosen in the Word pane when the letter is made.

✓ filled   ◐ best effort — filled when Equinox returns it; check the first letter, and run step26_probeLetter if it comes out empty   ✗ not available here (reason given)

Rules: a code with nothing in Equinox is left empty, and a line left holding only its label (e.g. "By email:") is dropped. A code the add-on doesn't know stays in the text so you notice it. Dates take offsets (#DATE+14D#, #NEXTFATAL-1M#, #H2DATE+30M#). #THUMBNAIL# and #USER_SIGNATURE# are pictures. Add-on-only codes start with EQX_; the letter itself goes where the master says #EQX_LETTER#.

Recipient — the person or organisation the letter is to

Chosen in the pane's To list: the matter's client (its key contact at the client's address) by default, or an associate, a separate billing address or an applicant. A content template can choose its default with <!-- to: associate -->.
